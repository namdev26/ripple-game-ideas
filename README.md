# IDEA

Mỗi idea nằm trong một thư mục riêng, đặt tên theo dạng `NNN-ten-ngan-gon`, ví dụ `001-game-nau-an`.

## Cách thêm idea mới

1. Copy thư mục `_template` và đổi tên thành `NNN-ten-idea` (lấy số tiếp theo).
2. Điền file `README.md` bên trong.
3. Các file khác của idea (ảnh, tài liệu, prototype...) để chung trong thư mục đó.
4. Thêm một dòng vào bảng bên dưới.

Idea bỏ hoặc tạm dừng thì chuyển vào `_archive/` (giữ nguyên số).
